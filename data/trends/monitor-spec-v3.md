# 跨境美妆多平台监控方案 v3

> 版本：v3（2026-08-12）｜升级点：每爆款必须附真实商品链接+图片；每细分类目 ≥20 单品；每类目双榜（销量最大 Top + 本周暴涨 Top）

## 1. 区域-平台矩阵（不变）

| 区域 | 平台 |
|---|---|
| 东南亚 | Shopee、Lazada、TikTok Shop |
| 欧美 | Amazon、TikTok Shop、Temu |
| 南美 | Mercado Libre（美客多）、TikTok Shop |

## 2. 美妆大类与细分类目体系

## 3. 单品数据规范（v3 新增字段加粗）

| 字段 | 说明 | 必填 |
|---|---|---|
| 商品名 | 平台展示名 | 是 |
| 品牌 | — | 是 |
| 价格 | 原币种+折算 | 是 |
| 销量 | 周期销量/累计 | 是 |
| 环比 | 周环比/日环比 | 是（暴涨榜必填） |
| 评分/评论数 | — | 是 |
| **商品链接** | 平台真实商品页 URL | 是 |
| **图片链接** | 商品图 URL | 是 |
| 信号标签 | 直播占比/达人带货/内容热度 | 选填 |

## 4. 榜单规则（v3 强制）

- 每个细分类目至少 **20 个单品**；
- 每类目出 **2 张榜单**：
  - 榜单 A「销量最大 Top20」：按周期销量降序；
  - 榜单 B「本周暴涨 Top20」：按周环比/日环比降序（环比缺失则用趋势信号标注）。
- 每平台每日合计 ≥100 单品（= 5 个细分类目 × 20 单品）。

## 5. 链接与图片采集方式

| 平台 | 链接/图片来源 | 接入优先级 |
|---|---|---|
| Amazon | Best Sellers 页公开抓取（URL 含商品 ASIN，图片来自 media-amazon.com） | P0 |
| Temu | temu-listings-scraper / 分类畅销页 | P1 |
| TikTok Shop | 开放平台 API / FindNiche / FastMoss 详情页 | P1 |
| Shopee/Lazada | 开放平台 API / 榜单页 | P2 |
| Mercado Libre | 官方 API /trends、/highlights、/items（免费，无需 OAuth 读公开数据） | P0 |

## 6. 报告模板（v3）

每平台章节：
1. 平台概览（今日总览表）
2. 各细分类目：
   - 榜单 A：销量最大 Top20（商品名/品牌/价格/销量/评分/链接/图片）
   - 榜单 B：本周暴涨 Top20（商品名/品牌/价格/环比/链接/图片）
3. 平台趋势与信号

## 7. 落地路线图（不变，补齐顺序按 P0→P2）

- Phase 1：美客多官方 API + Amazon Best Sellers 抓取（需注册开发者应用/代理）
