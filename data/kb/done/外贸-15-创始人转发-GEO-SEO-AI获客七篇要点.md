> 只留对帛卉(化妆品代工,客户在海外)能落地的点;广告软文(询盘保、BuildAdmin)只记它们卖的逻辑。

## 1. 「一人公司」做 GEO:AI 引用的是平台,不是你的站(头条 2rvrOrNityg)

- 链路是「写内容 → 按平台规则改写 → 平台推荐 → AI 高频抓取 → 被引用」;AI 像只逛固定几个菜市场的采购员。
- **先做平台地图,别抄别人的**:挑行业里最常被问的 4 个问题,在目标引擎各搜一遍,把回答底部的引用来源全部记下来,谁被反复引用一目了然。国内实测:豆包引用源近半来自 CSDN / 头条 / 搜狐;不同行业生态完全不同。
- 一键分发是最不该用的功能:一篇稿在 5 个平台要 5 个版本(CSDN 5,000 字长文数字密度高;头条 1,500–3,000 字短段带情绪结尾留问句;搜狐 3,000–5,000 字新闻锚点)。
- **对帛卉**:买家在海外,引擎是 ChatGPT / Perplexity / Gemini,平台地图要自己跑(Reddit / LinkedIn / Quora / 行业媒体 / 我们自己的站)。打点显示本周引擎实时取回我们首页与法规页 169 次 —— 自己的站能被引,但要「一题一页 + 内链」;分发版本按平台重写,不复制。

## 2. 外贸谷歌 SEO 公司怎么评(头条 syviupQfjmA)

- 「保证首页」= 警报:没有正规服务商能保证排名;常见套路是冷门无价值长尾词、临时冲排名、验收后掉。
- 看流量质量不看名次:① 目标市场精准流量是否增长(核心市场德国就别算东南亚零散访客)② 关键词意图:盯商业调查型与交易型,带 supplier / manufacturer / wholesale / custom / private label 的词 ③ 停留与跳出 ④ 询盘数量与质量同步升。
- 技术 SEO 是地基:可抓取可索引、目标市场打开速度、移动端、结构化数据、hreflang;国内服务器欧美打开 5–6 秒就是死穴。
- **对帛卉**:边缘部署 + hreflang + schema 已有;缺的是意图词覆盖清单(按市场 × 品类的 supplier / OEM / private label 落地页)和 Search Console 真实搜索词。

## 3. 零经验工厂找国外客户(头条 7DKbN5z3tJo,询盘保软文)

- 卖点逻辑:AI 锁定采购商 → 工厂自己判定精准度 → 不精准不收费 → AI 自动跟进 → 全流程陪跑。传统四条路(展会 / B2B 平台 / 招业务员 / 谷歌投放)成本与可控性表。
- **对帛卉**:我们自己的定向外联流水线就是这套逻辑的自建版;可借的是「工厂自主判定精准度」这个交互(后台外联名单的 A/B/C 级由业务员点,不由模型定)。

## 4. BuildAdmin 中小企业 GEO 建站(头条 WB3VzdoveoM,产品软文)

- 有用的一句:网站要「被搜索引擎和生成式引擎理解」—— 语义化结构、问答沉淀成知识库、产品参数结构化输出。其余是建站系统广告,我们有自己的站,不换。

## 5. Hypit:AI 克隆爆款视频(头条 eOH0KSWENFY)

- 开源,2.4K Star:丢一条跑通的广告视频,Agent 拆成 .svml 工作流(台词 / 画面 / 字幕 / 语音 / 合成),改一句台词整条同步,一个模板出 100 个变体;场景:Meta Ad Library 抓广告换自家产品、带货换 SKU、多语言本地化、A/B 测 50 个开头。要 Node 22.15+ 与支持 skills 的编程助手。
- **对帛卉**:产品视频线(STORYBOARD)的候选工具,尤其多语言版本;暂不上,记入 AI-VIDEO-STACK。

## 6. OpenDesign:开源本地 AI 设计工作台(头条 ejdeQjil7zc)

- 9.5 万 Star,接本地 AI 编程助手,内置 150 套品牌级设计规范(Stripe / Shopify / Linear),先锁规范再出图。
- **对帛卉**:官网改版做原型时可试;我们已有 DESIGN.md(Apple 设计层),按自己的规范走。

## 7. Ever Gauzy:开源自托管 ERP + CRM + HR + 项目(头条 xXFVFhGwMRw)

- 全栈 TypeScript,NestJS + Angular,PostgreSQL,多租户,REST + GraphQL。
- **对帛卉**:CRM 底座已定案(社区版底座 + 自建),Gauzy 记为第三候选,不换。
