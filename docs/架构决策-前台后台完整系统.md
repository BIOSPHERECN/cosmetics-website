# 架构决策:从「纯静态站」转向「前台 + 后台完整系统」

> 2026-08-11。创始人原话:「不是简单的一个页面啊,我要的是有前台,有后台」
> 「是一个完整的架构,而不是一个单页忽悠人」。
>
> **我认这个批评。** 我把交付物定成了「静态网站」,而创始人要的是「运营能自己改的系统」。
> 这不是细节偏差,是架构层的定错方向 —— 纯静态站改一个字都要重新构建,
> 运营根本无法自助,再漂亮也是死的。

## 一、现场勘查(创始人已有资产)

CF 账号里 2026-07-28 已存在一套原型(opencode + Marvis 搭建):

| 资产 | 状态 |

| Pages `marvis-bohui` | 在线,Playfair Display + Inter,三套主题 |
| Pages `bohui-cosmetics` | 在线,**带 `/admin/` 后台** |
| D1 `bohui-cms` | 单张扁平 `content` 表,75 行 |

### 那套原型的接口(值得学的部分)
```
POST /api/admin/login
GET  /api/content?lang=&section=
POST /api/admin/update
```
前台 `fetch('/api/content?lang=')` 客户端渲染。

### 它的天花板在结构上,不在界面上
`content` 表是扁平键值(lang / section / key → value),所以:
- 没有产品库 → 做不了产品目录与详情页
- 没有媒体库 → **没法上传图片**(创始人最在意的一条)
- 没有多站 → 5 个品牌塞不进去
- 没有修订 → 改错了回不去

创始人评价:「他们搭建的后台惨不忍睹,千万别学」。
**结论:学它的架构分层,不学它的数据结构,更不学它的后台界面。**

## 二、新架构(全部落在现有 CF 账号,零新增月费)

| 层 | 技术 | 解决什么 |
|---|---|---|
| 前台 | Astro SSR on Workers | 改完**即时生效**,且 HTML 服务端渲染,SEO 不丢 |
| 接口 | Pages Functions `/api/*` | 内容读写、登录、上传、询盘 |
| 内容库 | **D1 `bohui-cms-v2`** | 13 张表,结构化,见 `packages/cms/schema.sql` |
| 图片库 | **R2** | 拖拽上传,自动派生 WebP/AVIF 多尺寸 |
| 后台 | 自研 `/admin/` | 四语同屏 + 富文本 + 拖拽传图 + 实时预览 + 一键发布 |

### 为什么不用昨晚推荐的 Directus
昨晚推荐 Directus 的前提是「需要一台常驻服务器」。但创始人指出 CF 能力已足够,
且账号里已有 D1 + Workers 的可用原型。**在 CF 上自建 = 零新增月费 + 同账号 + 与已有资产同构**,
比引入一台 VPS 更合理。Directus 方案作废,`docs/后台选型决策.md` 已被本文取代。

### 数据结构要点(`packages/cms/schema.sql`,13 张表,已上线)
- 多语言用 `*_i18n` 分表(`site_i18n` / `page_i18n` / `block_i18n` / `product_i18n`)
  → 加一门语言不改表结构,且能查出「哪些内容还缺某语言」
- `pages.parent_id` 支持**两级导航**(标杆站 Intercos 6 顶级 × 15 二级、KDC-One 7 顶级)
- `blocks` + `sort_order` → 运营可拖拽调版块顺序(Shopify Section 式体验)
- `media.folder` 用于分类;**R2 的 key 一次写定永不搬移**
  (`zero-r2-move` 铁律:事后 copy 搬图曾一天烧 $40,分类只改字段)
- `revisions` 存改动前后,改错能回滚
- `inquiries` 落地页表单直接落库(PDF 第 7 屏「提交即进系统询盘池」)

## 四、同时在改的视觉层(见 `docs/标杆站实测与改造方案.md`)

实测标杆站后确认的三条硬差距,已开始整改:
1. **字体**:标杆全部是「显示体 + 正文体」配对(Intercos: BebasNeue + Futura;
   KDC-One: Nantes + Untitled Sans;Summer Fridays: Expressa + futura-pt)。
   已安装 5 款 **SIL OFL 开源**自托管字体:Jost(Futura 复刻)/ Bebas Neue /
   Archivo / Fraunces / Instrument Serif —— 外部请求仍为 0。
2. **字号**:标杆正文 18–20px、标题 80–178px;我原来是 16px / 64px。
3. **近黑不用纯黑**:Summer Fridays `#000418`(偏蓝)、Boka `#202722`(偏绿)、
   Quip `#054040`(偏青)。创始人指定参考 Summer Fridays,其调色板按「一天的光」命名:
   `--morning-sky #5C7899` / `--afternoon-sky #ACD5E9` / `--chalk #EEEDEC` / `--clay #D5D1CA`。
